# Car Showcase Application

This is a Next.js application for showcasing cars. It allows users to browse through a collection of cars, view details, and perform searches.

## Features

- Browse a collection of cars
- View detailed information about each car
- Search for cars by various criteria

## Getting Started

To get started with the project, follow these steps:

### Prerequisites

Make sure you have the following installed on your machine:

<!-- @import "[TOC]" {cmd="toc" depthFrom=1 depthTo=6 orderedList=false} -->

- Node.js (>=14.x)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/car_showcase.git
   ```

2. Navigate to the project directory:

   ```bash
   cd car_showcase
   ```

3. Install the dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

### Running the Development Server

To start the development server, run:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

To build the application for production, run:

```bash
npm run build
# or
yarn build
```

### Running in Production Mode

To run the application in production mode, run:

```bash
npm start
# or
yarn start
```
